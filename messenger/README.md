# Мессенджер от Фокса 😺

Сайт-мессенджер в стиле 2007–2010 годов на Python (Flask).

## Возможности
- Регистрация и вход по логину/паролю (пароли хранятся в виде хэша, не в открытом виде)
- Лента постов — любой может публиковать сообщения
- Реакции на посты: 😺 лайк / 😾 дизлайк
- Комментарии под постами
- Личные сообщения (чат один на один) между пользователями
- Кнопка «Жалоба 🚩» — пользователи могут пожаловаться на пост (18+, жестокость, издевательства над животными и т.д.)
- Админ-панель: просмотр жалоб, удаление постов, назначение других админов
- Смайлики в стиле 2010 года при написании постов, комментариев и сообщений
- Ретро-дизайн: градиенты, Verdana/Comic Sans, глянцевые кнопки, бегущая строка

## Как запустить

1. Установи Python 3.10+ и зависимости:
```bash
pip install -r requirements.txt
```

2. Запусти сервер:
```bash
python app.py
```

3. Открой в браузере: http://127.0.0.1:5000

При первом запуске автоматически создаётся файл базы данных `messenger.db`.

## Кто становится администратором?

**Первый зарегистрированный пользователь** автоматически получает права администратора.
Поэтому зарегистрируйся первым — и у тебя сразу будет доступ к разделу «⚙ Админка»,
где можно смотреть жалобы на посты и удалять запрещённый контент (18+, расчленёнка,
издевательства над животными и т.п.), а также назначать других пользователей админами.

## Важно перед реальным использованием

Это учебный/базовый проект. Если планируешь выложить сайт в открытый доступ:
- Смени `SECRET_KEY` в `app.py` на свой собственный секретный набор символов
- Используй HTTPS (например, через nginx + Let's Encrypt)
- Добавь ограничение на частоту запросов (rate limiting), чтобы защититься от спама
- Для реальных данных лучше перейти с SQLite на PostgreSQL
- Автоматической проверки изображений/видео на запрещённый контент здесь нет —
  модерация полностью держится на жалобах пользователей и ручных действиях админа
